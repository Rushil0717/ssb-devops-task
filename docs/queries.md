# Core SQL Queries & Explanations
- `SELECT * FROM tasks ORDER BY id DESC;` — Retrieves all task records ordered from newest to oldest.
- `INSERT INTO tasks (title, status) VALUES ('Audit permissions', 'pending');` — Creates a new task record.
- `UPDATE tasks SET status = 'completed' WHERE id = 2;` — Updates an existing task's status to completed.
- `DELETE FROM tasks WHERE id = 3;` — Deletes a specific task record by primary key ID.
